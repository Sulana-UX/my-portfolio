# My Portfolio

Personal portfolio website built with HTML, CSS, JavaScript and GSAP.

## Features

- Dark, editorial-style design
- Animated intro loader and large name reveal with the portrait in front
- Mouse parallax and scroll animations (GSAP ScrollTrigger)
- Scroll-reactive marquee and word-by-word text reveal
- Fully responsive

## Tech

- HTML5, CSS3, vanilla JavaScript
- [GSAP](https://gsap.com/) + ScrollTrigger
- Google Fonts: Anton, Instrument Serif, Inter

## Run locally

No build step needed. Open `index.html` in a browser.
