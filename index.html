Luxury Cinema Booking

03TraceMind AI

Digital Evidence Story Builder

Local-first cybersecurity and digital forensics platform that correlates multi-source security logs, reconstructs the attack timeline and builds an audit-ready incident report — no cloud or paid APIs.

Key features

  • Streams multi-gigabyte log dumps line by line, runs within 8 GB of RAM
  • Multi-stage correlation from failed logons to compromise and data exfiltration
  • Interactive graph of users, hosts and processes showing lateral movement
  • Isolation Forest machine learning to flag anomalous behaviour
  • SHA-256 integrity hashes and HTML, PDF and JSON report exports
  • Python
  • Streamlit
  • Scikit-learn
  • NetworkX
  • Plotly
  • Pytest
